# Tài liệu dự án DPCT

Trang này là mục lục tài liệu chính của dự án. README ở thư mục gốc dành cho giới thiệu nhanh; thư mục `docs/` dành cho cài đặt, vận hành và tham khảo khi phát triển.

## Tài liệu chính

| Tài liệu | Nội dung |
|---|---|
| [SETUP_GUIDE.md](SETUP_GUIDE.md) | Cài đặt local, env, database, chạy web/API. |
| [SYSTEM_DOCUMENTATION.md](SYSTEM_DOCUMENTATION.md) | Tổng quan kiến trúc, module, dữ liệu và luồng chính. |
| [API_REFERENCE.md](API_REFERENCE.md) | Danh sách endpoint backend theo nhóm chức năng. |
| [ADMIN_AUTH.md](ADMIN_AUTH.md) | Xác thực, phân quyền admin và tình nguyện viên. |
| [USER_GUIDE.md](USER_GUIDE.md) | Hướng dẫn sử dụng nhanh theo từng vai trò. |
| [DEPLOYMENT.md](DEPLOYMENT.md) | Gợi ý triển khai web/API/database. |
| [PROGRESS.md](PROGRESS.md) | Trạng thái hiện tại và phạm vi đã hoàn thiện. |

## Cách đọc nhanh

- Muốn chạy dự án: đọc [SETUP_GUIDE.md](SETUP_GUIDE.md).
- Muốn hiểu hệ thống: đọc [SYSTEM_DOCUMENTATION.md](SYSTEM_DOCUMENTATION.md).
- Muốn gọi API hoặc sửa frontend hook: đọc [API_REFERENCE.md](API_REFERENCE.md).
- Muốn biết quyền truy cập: đọc [ADMIN_AUTH.md](ADMIN_AUTH.md).
- Muốn demo sản phẩm: đọc [USER_GUIDE.md](USER_GUIDE.md).
